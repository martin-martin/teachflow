Problem 4 (Code Writing):
Q: Write a function that returns true if a singly linked list contains a cycle (Floyd’s algorithm).
A:
```
def has_cycle(head):
    slow = head
    fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False
```

Problem 5 (Short Essay):
Q: Compare arrays and liked lists in terms of memory layout, random access, and typical use cases.
A: Arrays use contiguous memory, enable O(1) index access, and fit cache-friendly workloads. Linked lists use scattered nodes, have O(n) index access, but excel at frequent insertions/deletions without shifting elements. Choose arrays for indexing-heavy tasks; choose lists when resizing and splicing dominate.
